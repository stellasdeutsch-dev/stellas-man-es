# man & es — Stellas Deutsch

Одностраничный урок немецкой грамматики (неопределённо-личные и безличные предложения)
в связке с презентацией платформы Stellas.

- `index.html` — разметка
- `styles.css` — визуальная система (Onest, чёрно-белый контраст, mobile-first)
- `app.js` — анимации, квиз, «машина порядка слов», аккордеон
- `media/` — сжатые видео и скриншоты платформы

## Ссылки

Все кнопки покупки берутся из объекта `LINKS` в начале `app.js`:

```js
const LINKS = {
  checkout : 'https://app.lava.top/801303618?tabId=products&sort=published',
  instagram: 'https://instagram.com/stellas_deutsch'
};
```

Поменяй их там — они подставятся во все CTA сразу.
Кнопки «Начать урок» и «Посмотреть, что внутри» — это внутренние якори, они не трогаются.

## Важно при обновлении

`index.html` подключает стили и скрипт с версией: `styles.css?v=2`, `app.js?v=2`.
Если правишь CSS или JS — **подними номер версии в обоих местах**, иначе у тех,
кто уже заходил на сайт, останется старая закешированная версия
(и, например, старая ссылка на оплату).
